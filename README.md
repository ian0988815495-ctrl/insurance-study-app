# 人身保險私人題庫

僅供本機使用的人身保險私人題庫網站。

## 啟動

在此資料夾執行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1
```

開啟 <http://127.0.0.1:5173>。

服務只會監聽本機 `127.0.0.1`，不會公開到網路。

## 開發檢查

```powershell
npm run lint
npm test
npm run build
```

## iPhone 加密版

建立手機離線安裝包：

```powershell
npm run build:offline
```

輸出資料夾為 `dist-offline`。建置前必須在未提交的 `.env` 設定至少 8 個字元的 `OFFLINE_UNLOCK_PASSWORD`。題庫會以 AES-256-GCM 加密後才寫入部署檔；答題紀錄、已掌握題目與考試日期只保存在 iPhone 本機。首次以 HTTPS 開啟並加入主畫面後，即可在沒有開啟電腦的情況下使用。

GitHub Pages 網址與網站程式碼會公開，但部署內容不含原始資料庫、明文題庫、`.env` 或解鎖密碼。換手機前請先在「備份與還原」匯出 JSON，並在新裝置確認後還原。

## 驗收範圍

- 一般練習沒有時間限制，未作答也能按下「公布答案」並標記待複習。
- 模考在交卷或時間到之前不顯示答案或解析。
- 題庫為空時顯示可返回首頁的提示。
- 可在首頁設定考試日期；系統依到期複習、錯題與新題安排今日練習。
- 讀書計畫、複習排程與備份資料只保存在本機。
- 題目資料由使用者在 Codex 對話中提供後，以內部預覽與確認流程處理；正式產品不提供上傳功能。

## 資料安全

- `.env` 僅供本機 API 與加密建置使用，不能提交到 Git。
- 不得保存 Cookie、Token、登入資料或可用於第三方服務的密碼。
- 解鎖密碼僅保存在未提交的 `.env`；使用者選擇「記住這台裝置」時，密碼會留在該裝置的瀏覽器本機資料中。
- 還原前先使用備份預覽；系統會先建立還原前備份。
