# Offline iPhone PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build an installable iPhone PWA that contains the private question bank and remains usable without the PC running.

**Architecture:** Keep the existing local API application unchanged. Add a separate static mobile build that bundles a read-only question seed, saves progress in versioned browser local storage, and caches all assets with a service worker. The mobile build uses explicit JSON backup and restore rather than silent server synchronization.

**Tech Stack:** React, TypeScript, Vite, IndexedDB, Web App Manifest, Service Worker.

## Global Constraints

- The mobile app must work after its first successful HTTPS load without a PC connection.
- Question content, answers, source explanations, and personal attempt history must remain local to the device.
- Do not publish the question seed to an unauthenticated public site.
- Preserve the existing desktop API behavior and database.
- Use the source explanation display rules already used by the desktop app.
