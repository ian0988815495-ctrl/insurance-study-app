# 固定模考與題目匯入設計

## 目標

讓私人題庫網站提供固定規格的單科模考與完整測驗，並恢復由使用者主動提供資料的題目匯入流程。

## 範圍

### 固定模考

- 保險法規單科模考固定為 100 題、80 分鐘、每題 1 分，及格分數為 60 分。
- 保險實務單科模考固定為 50 題、60 分鐘、每題 2 分，及格分數為 60 分。
- 完整測驗由法規與實務兩個獨立階段組成；使用者可在兩階段之間離開或休息。
- 完整測驗兩科都完成後才計算最終結果。通過條件為法規至少 60 分、實務至少 60 分、兩科合計至少 140 分。
- 模考作答期間不得顯示答案、正確性或解析；交卷或時間到才顯示結果與解析。
- 前端不顯示題數、分鐘或及格門檻的手動輸入欄位。
- 一般練習沒有時間限制。使用者可以先選擇答案再查看答案，也可以不作答直接查看答案。
- 一般練習未作答就查看答案時，題目標記為「看過答案／待複習」，不計入答錯次數。

### 題目匯入

- 第一階段提供貼上資料的匯入頁。使用者填寫科目、章節、題幹、任意數量的選項、正確答案與原始解析。
- 匯入頁先執行格式與重複題檢查，只有使用者按下確認後才寫入題庫。
- 題目正確答案以選項 ID 保存，不依賴選項的顯示順序。
- 原始解析與 AI 白話解析分開保存；AI 無法產生內容時維持待確認，不自行編造。
- 第二階段使用本機 Chrome 擴充功能，在使用者已登入且主動觸發時讀取題目頁的可見內容。擴充功能把內容送往本機預覽，不保存 Cookie、Token、密碼或登入資料。
- 開始前必須在使用者可正常存取的環境中分析使用者提供連結的實際題目模板、選項、答案、解析、科目、章節與切換方式；不得依通用爬蟲假設網站 HTML 或 API 結構。
- 第二階段不得繞過登入、驗證碼或其他安全機制。無法讀取登入後內容時，停止自動擷取並要求使用者提供合法取得的頁面內容或匯出資料。

## 架構

- 後端新增固定模考設定與完整測驗流程，不接受前端任意覆寫官方題數、時間與門檻。
- 題目匯入沿用預覽與明確確認兩步驟。寫入時建立題目、可變長選項、原始解析與待確認的 AI 解析紀錄。
- 瀏覽器擴充功能只負責把已登入頁面的可見內容交給預覽流程；解析與寫入仍由本機 API 執行，且必須經過使用者確認。
- 練習與模考題目回應都不含正確答案。答案只由查看答案端點或交卷端點在適當時間處理。

## 資料安全

- 不刪除既有題庫、作答紀錄或備份。
- 還原流程維持先預覽、明確確認與還原前備份。
- 不在前端、資料庫備份或可提交檔案保存敏感登入資料。

## 驗收條件

1. 法規與實務單科模考可由固定按鈕建立，不出現手動設定表單。
2. 法規模考只會建立 100 題與 80 分鐘的設定；實務只會建立 50 題與 60 分鐘的設定。
3. 完整測驗必須完成兩科，並依單科 60 分與總分 140 分判定通過。
4. 模考交卷前的題目資料不含答案與解析。
5. 一般練習沒有倒數時間，未作答也能查看答案，且會建立待複習紀錄但不算答錯。
6. 貼上或瀏覽器擷取資料的預覽不會寫入題庫；確認後才寫入，且選項重排後仍能正確判分。
7. 缺少必要資料、無法判定答案或發現重複題時，預覽會阻止確認寫入。
8. 所有相關測試、型別檢查與正式建置通過。
