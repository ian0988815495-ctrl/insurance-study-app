# 免費加密雲端題庫設計

## 目標

在不使用付款方式、帳號系統或常駐電腦的前提下，讓手機可透過 HTTPS 使用題庫，同時避免題目以明文放在公開網站。

## 設計

- Cloudflare Pages 僅提供靜態前端與加密後的題庫檔。
- 建置時以使用者專用密碼透過 PBKDF2-SHA-256 衍生 AES-256-GCM 金鑰，加密 `offline-seed.json`。
- 網站啟動時先顯示解鎖畫面；密碼正確後才在瀏覽器記憶體中解密並載入題庫。
- 使用者可選擇在目前裝置記住解鎖狀態。該設定只留在此裝置的瀏覽器中，刪除網站資料後需重新輸入密碼。
- Service Worker 只快取加密檔，不快取明文題庫。

## 範圍與限制

- 不新增雲端帳號、付款資料、伺服器 API 或跨裝置同步。
- 已有作答紀錄繼續保留在各裝置的本機瀏覽器，不會自動同步。
- 使用強密碼可保護公開網站中的加密題庫；密碼遺失時需使用本機原始資料重新建立加密檔。

## 驗證

- 正確密碼可解密範例題庫。
- 錯誤密碼不能解密。
- 離線建置不產生明文 `offline-seed.json`。
- TypeScript 檢查與離線建置通過。
