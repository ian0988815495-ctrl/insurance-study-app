# 私人題庫正式產品範圍設計

## 目標

將網站收斂為一般使用者熟悉的刷題 App：首頁、練習、正式模考與備份。題目維護不再出現在產品介面，而由使用者在 Codex 對話提供合法取得的內容後，以內部流程處理。

## 使用者介面

- 移除首頁的「題目匯入」入口。
- 移除底部導覽的「匯入」分頁。
- 移除題目匯入頁與網址帶入預覽流程。
- 保留首頁、練習、正式模考、備份與還原。
- 正式產品畫面、操作文件與測試不顯示外部來源或上傳功能。

## 內部資料處理

- 保留既有資料庫資料、練習紀錄、模考紀錄與備份功能。
- 保留伺服器端的預覽確認匯入服務，供後續由 Codex 處理使用者在對話中提供的合法資料；服務不會出現在網站介面。
- 移除 Chrome 擴充功能，避免產品提供登入後頁面擷取、外部網站來源或上傳入口。
- 內部匯入仍必須遵守預覽、重複題檢查、使用者確認後寫入，以及不保存登入資料的限制。

## 測試與驗收

- 首頁與底部導覽只保留首頁、練習、模考、備份。
- 前端程式不載入匯入頁，也不顯示題目上傳文案。
- 既有 API 匯入預覽測試仍保留，確保未來內部資料處理安全。
- 移除擴充功能相關安全測試，改為檢查正式前端不存在匯入入口與外部來源品牌文字。
- 執行完整測試、型別檢查、建置與手機尺寸畫面檢查。

## 範圍界線

- 本次不刪除資料庫中的任何題目、作答、模考或備份資料。
- 本次不改變練習、常錯題、模考與備份的既有行為。
- 本次不新增後台管理頁；題目維護由使用者在 Codex 對話中提出需求後再執行。
