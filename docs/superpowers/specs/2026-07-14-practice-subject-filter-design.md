# 練習科目篩選設計

## 目的

讓日常練習能依「全部、法規、實務」篩選題目，同時保留既有的順序、隨機、錯題與常錯題模式。一般練習可在尚未作答前查看答案；正式模考則維持交卷或時間結束後才公布答案。

## 使用流程

1. 使用者進入練習設定頁。
2. 先選擇科目：`全部`、`法規` 或 `實務`；預設為 `全部`。
3. 再選擇練習模式：順序、隨機、錯題或常錯題。
4. 視模式調整隨機考題與打亂選項設定後開始練習。

「法規 + 常錯題」等組合只會顯示同時符合科目與常錯條件的題目。若沒有符合題目，沿用目前的空題提示，不建立無效練習。

## 前端設計

在練習設定頁的模式選擇前新增三段式科目控制項：全部、法規、實務。

- 選擇狀態會與既有練習模式、隨機考題、打亂選項一起送出。
- 一般練習頁維持「查看答案」按鈕；無論是否已選擇選項，使用者都可以揭示正確答案與解析。
- 正式模考頁不新增答案揭示控制項；僅在交卷或自動交卷後顯示結果與檢討內容。

## 後端與資料流

- 練習建立請求新增可選的 `subject` 欄位，值為 `all`、`law` 或 `practice`，預設 `all`。
- 資料庫查詢先依科目縮小題目範圍，再套用目前模式的條件：未掌握、錯題或常錯題。
- 題目順序與選項打亂邏輯不變，正確答案仍依穩定選項 ID 判定。
- 建立後的練習沿用既有題目清單保存方式；本次不增加歷史紀錄欄位。
- 固定模考的出題、時間與答案揭示規則不變，不共用日常練習的答案揭示流程。

## 錯誤處理

- 不接受未知科目值，回傳既有格式的驗證錯誤。
- 所選科目與模式沒有任何題目時，前端顯示目前的無題目提示，避免進入空白刷題頁。
- 舊的未含 `subject` 請求與既有練習紀錄視為 `all`，避免資料相容性問題。

## 測試

- 後端：驗證三種科目值、未知值拒絕、法規與實務的順序/隨機/錯題/常錯題交集篩選。
- 前端：預設選取全部、切換科目會送出正確值，以及一般練習即使未作答也可查看答案。
- 回歸：正式模考在交卷前不顯示正確答案或解析。

## 範圍限制

本次不調整題目匯入、題目內容、正式模考配題、時間設定、讀書計畫或備份資料格式。
